# Example configuration

The .env.dev.json, .env.stage.json and .env.prod.json files contain non-working example API URLs and AppMetrica keys. Supply your own values locally before using the integrations. Sentry is disabled with an empty SENTRY_DSN. Google/Firebase service configuration files, if needed, must be generated locally and are ignored by Git.

Values containing `EXAMPLE`, zero-only identifiers and `example.com` domains are placeholders, not real credentials. Never use these example credentials in production.
